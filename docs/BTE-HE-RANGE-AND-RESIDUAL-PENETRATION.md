# HE 范围衰减与剩余穿深伤害

击穿后额外乘以剩余穿深比例：`clamp((P有效 - 装甲厚度) / P原始, 0, 1)`。该项乘在已经结算的击穿伤害上；未击穿 AP/APCR/HEAT 仍为 0，HE 未击穿补偿仍为 10%。

AP 基础系数 K 为 35.21；弹种系数、AP 装药增伤保持原式。穿深倍率维持 1～2：`1 + 2 * (clamp(P有效/装甲厚度,1,1.5)-1)`。HE、HEAT 仍按 K_HE 与装药公式。

HE 范围衰减尚未接入游戏回调：当前工程没有游戏 APK/IL2CPP 运行库，`CalDamage` hook 只暴露受击装甲区和穿深，不提供爆炸中心到目标距离或原弹爆炸半径。取得这两个运行时量后，才可准确实现并验证衰减曲线。

验证覆盖穿深比例、倍率上限、HE 击穿剩余量、未击穿边界、HE 原 10% 补偿及装药项。
