# 更好的坦克体验0.1：穿深伤害最高加成100%

仅调整穿透后由穿深富余带来的额外伤害，穿深富余加成最高为100%。

令 r = 有效穿深 / 装甲厚度。原倍率为 clamp(r,1,1.5)，新倍率为：

`1 + 2 * (clamp(r,1,1.5) - 1)`。

例如恰好击穿仍为1倍；r=1.2时从1.2变为1.4；r>=1.5时从1.5变为2.0。装甲为0时沿用最高档处理，对应2.0倍。

该倍率用于AP、APCR和HEAT已有的穿透后伤害路径。穿透判定、角度修正、基础系数、各车装药和HE未击穿10%补偿不变。HE本来就没有富余穿深倍率，本次不增加新机制。游戏最终整数化和255上限仍可能使显示增幅小于浮点公式增幅。

公式位于坦无敌3000前置原生模块。已有“更好的坦克体验”数据/语音配置继续使用；需要手动替换前置模块并完全重启游戏，单独重新导入未改的玩法JSON不能生效。

可用 `scripts/build_mods.py --module-only` 构建加载器和前置，无需重新打包语音。

验证：C公式回归覆盖3种弹药、6档穿深比例、未击穿边界、原HE补偿、装药和非法输入。Android实机效果未验证。
