# 炼狱之门：苏德双阵营

从「额外战役 → 巴巴罗萨行动」进入战役选择页。「炼狱之门」下方有两个原版风格的按钮；点击后即开战，不再经过车库或确认框。

| 按钮 | 玩家车 | 村口阵地的胜负判定 |
| --- | --- | --- |
| 德国 · 进攻 | 二号 F 型 | 按原版进攻规则，德军一方抵达阵地即可夺点。 |
| 苏联 · 防守 | T26 | 击退整波德军且没有失守时获胜；德军抵达阵地则失败。防守没有额外倒计时。 |

两条路线是同一场战斗，初始位置和阵容相同。苏军在村口附近部署 5 辆 T26、3 辆 BT7、2 辆原版深绿色 T34-76；德军共 2 辆四号 C 型、3 辆二号 F 型、3 辆三号 J 型、3 辆 38(t)。玩家接管其中一辆，余下二十辆由 AI 操控。任务说明、开局提示、阵营识别和重试入口随所选阵营切换。

两个入口使用同一套原版 UGUI 样式、独立触摸区域与显式方向键导航。上一版的苏军场景仍在槽 22，德军使用槽 23，通用地图仍在槽 21。苏军采用原版「敌军全灭获胜、敌军抵达失败」的防守触发器设置，德军沿用原版抵达据点的进攻设置。两边都保留原版战斗 HUD 和据点碰撞体。场景内的本阵营备用玩家槽也指向对应车型。

从仓库根目录构建；`--prior` 传入上一版单阵营战役包，亦支持之前的 PanzerIV-C-Integration.zip。输出目录应和输入包分开。

```bash
python -m tankbuilder.barbarossa.mission.release \
  --apk Hatch-0.4-Grille-HE200-T26.apk \
  --prior previous/Barbarossa-01-Gates-of-Hell.zip \
  --output out/latest --work out/mission01-work
```

构建工具重新读取实际写出的场景，检查两个菜单按钮、玩家控制和备用生成器、阵容、同一辆车在两边的出生位置、目标碰撞体和原版胜负开关、AI 路线、HUD 及重试。生成的 ZIP 可从原始 APK 直接还原最新资源，无须层叠旧补丁。自动检查不替代 Android 实机触屏试玩与通关。
