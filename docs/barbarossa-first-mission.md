# 炼狱之门：巴巴罗萨第一场战役

点击「额外战役 → 巴巴罗萨行动 → 炼狱之门」的任务栏，直接进入西波列西亚乡野。玩家驾驶 T26，与友军夺取村口阵地。沿用原版苏军第一关的玩家控制、战斗 HUD、指令、据点触发器和结算界面。「重新开始」重载本关；目前没有第二关，结算后的后续入口返回标题。

苏军 10 辆，包含玩家 T26：其余为 T26 ×4、BT7 ×3、原版深绿色 T34-76 ×2。德军 11 辆：四号 C 型 ×2、二号 F 型 ×3、三号 J 型 ×3、38(t) ×3。两辆 T34-76 都使用普通版车身、炮塔和炮管的原版材质，1943 版的三种材质未被引用。

工程在既有标题场景的任务栏添加原版 UGUI Button，固定载入新场景 22。新场景使用独立路径，沿用原版战场文件的末级名称，兼容按场景名识别第一战场的组件。已有的原版场景及通用地图 21 保留。每辆车都有独立的驾驶、悬挂和射击组件；菜单的先前选车和本关苏军备用玩家槽都不能把车模型替换成别的车型。新中文文字带自己的字体字形，地图继续使用原版小地图控件绘制实时标记。

在仓库根目录安装原有构建依赖后，生成并校验可分发的累积资源包：

```bash
python -m tankbuilder.barbarossa.mission.release \
  --apk Hatch-0.4-Grille-HE200-T26.apk \
  --prior PanzerIV-C-Integration.zip \
  --output ./out/mission01 --work ./out/mission01-work
```

构建工具会重新读取交付的 Unity 场景，检查入口、玩家和 AI 数量、阵营、父子层级、炮塔与控制器引用、原版材质、小地图、出生间距、道路与障碍、目标点以及重试。输出目录的 ZIP 可以从原始 APK 还原游戏数据；具体步骤在包内的 README-zh.md 中。自动验证不覆盖 Android 触屏实玩、设备帧率或实际通关存档。
