# 蟋蟀局部发黑：材质修订

基线：367b3b4（Android 5.1.0 游戏的 Hatch 0.4 加载器，不是可打开的 Unity Editor 工程）。

用户截图中外侧迷彩正常，战斗室内多个部件近黑。检查原始 GLB：

- blinn19 用于 Hull_Visual 的一个 17490 顶点子网格，底色约 (0.050, 0.044, 0.044)。
- blinn20 用于 Barrel_Recoil、Gun_Carriage、Hull_Visual 三个子网格，共20613顶点，底色约 (0.048, 0.044, 0.044)。
- 这两种材质无底色贴图；加载器使用因子着色，并没有缺失它们的贴图。
- 全模型材质均无 normalTexture；检查到的顶点法线长度约为1，不能据此归因为法线贴图或法线缺失。
- 当前加载器不保留完整源模型的镜面材质表现；低漫反射底色在这条渲染路径下很难分辨轮廓。这与截图一致，但没有目标手机GPU复现，不能声称已完成实机根因确认。

## 修订

只将 blinn19 调整为 (0.24,0.22,0.22,1)，blinn20 调整为 (0.23,0.22,0.22,1)，用于当前漫反射材质路径的深灰色金属外观。这是两项明确的资产配色修订，不是全局Gamma修正，也不改变其他车型。

保留其余14个材质（包括孔洞黑色）、所有网格/UV/法线/节点、6张贴图、炮架/炮管/轮组绑定。修订保持GLB总长度和BIN块偏移，只改变JSON块；仅第0模型分片和分片指纹改变。脚本保留原始色值，可复现、可逆，并拒绝未知材质基线。

## 验证

- 2项专项回归通过：两项材质范围、BIN块逐字节保留、节点/网格保留、幂等、错误输入拒绝。
- 现有双面网格测试通过；原上传源GLB不在工作区，其来源对照测试跳过，未计入通过项。
- 生产打包器生成并校验 Grille-Hatch-0.4-Material-Fix.hatch，140节点、6贴图。
- C生产加载流程通过：106个网格、纹理加载/材质赋值、双面、武器挂点、弹体和机枪粒子保留，以及失败路径。
- 未执行Unity/GPU或Android实机渲染。仍需在原战斗场景同角度/照明下复测，并转动镜头检查炮架和车内部件。

## 使用

在舱盖手动导入修订的Grille包，替换同ID旧模组，完全退出游戏并重启，然后在新对局重新切换蟋蟀。只替换仓库文件或重启而未导入新包，不会修改手机已安装的旧材质。
