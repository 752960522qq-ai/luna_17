# 巴巴罗萨行动 · 第一战「炼狱之门」

进入「额外战役 → 巴巴罗萨行动」，点击「炼狱之门」即进入西波列西亚战场。指挥一辆 T26，与友军夺取村口阵地。原版战役的瞄准、驾驶、友军指令和据点判定沿用原设置。

| 阵营 | 车辆 |
| --- | --- |
| 玩家 | T26 ×1 |
| 友军 AI | T26 ×4、BT7 ×3、原版深绿色 T34-76 ×2 |
| 敌军 AI | 四号 C 型 ×2、二号 F 型 ×3、三号 J 型 ×3、38(t) ×3 |

本包是适用于 Hatch 0.4 蟋蟀 HE200 含 T26 基线的累积战役资源包，不是可直接安装的 APK。带有此前版本的车辆目录、三组新增载具包、原版风格菜单和通用地图。不要把里面的文件直接覆盖手机的存档目录。

解压后用仓库的 Python 资源工具运行：

```bash
python apply_overlay.py Hatch-0.4-Grille-HE200-T26.apk data.unity3d
```

输出文件须不存在。它对应 APK 内的 `assets/bin/Data/data.unity3d`；组装游戏时还应包含包内 `assets/Hatch/` 的目录和车辆。工具校验输入、增量与输出 SHA-256。完整阵容和场景位置见 `mission.json`；实际交付物的场景回读检查见 `verification.json`。没有把资源回读当成 Android 实机通关测试。
