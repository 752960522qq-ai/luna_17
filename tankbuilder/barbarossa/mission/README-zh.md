# 巴巴罗萨行动 · 炼狱之门（双阵营）

进入「额外战役 → 巴巴罗萨行动」。在「炼狱之门」下任选一个按钮，直接开战；重试沿用刚选的阵营。

| 选择 | 驾驶 | 任务 |
| --- | --- | --- |
| 德国 · 进攻 | 二号 F 型 | 与友军夺取村口阵地。 |
| 苏联 · 防守 | T26 | 守住村口，消灭来袭德军。德军抵达阵地即告失守。 |

两边都是苏军 10 辆（T26 ×5、BT7 ×3、深绿色 T34-76 ×2）对德军 11 辆（四号 C 型 ×2、二号 F 型 ×3、三号 J 型 ×3、38(t) ×3）。玩家占所选阵营的一辆，不额外生成。

额外战役从实际选中的阵营开局。开局为 8 辆苏军轻坦与 6 辆德军轻坦；第 90 秒德军剩余 5 辆从东西两侧入场，第 150 秒两辆深绿色 T-34 从村后增援。苏方视角第 78 秒遭遇原版 Ju 87，德方视角第 135 秒遭遇原版伊尔-2。玩家可在第三人称与瞄准视角看到命中、击毁和阶段提示。苏军仍在村口防守；德军从北面远处进入，双方最近的两辆坦克开场相距约 567 米。

启动修复版沿用原签名，可直接覆盖安装。启动时等游戏画面就绪才显示「舱盖」和「坦无敌3000」；只有开始操作后，额外战役才查询场景。如游戏窗口连续 45 秒未收到画面就绪信号，右上角会出现「启动诊断」，可选择下次暂缓模组。如果连续两次启动中断，下一次会临时暂停模组，点「舱盖 · 恢复」可查看上次停在哪一步。进入主界面后完全退出再打开，即可恢复。

安装请优先使用同版完整 APK。单用旧前置无法处理新阵营入口。

这是适用于 Hatch 0.4 蟋蟀 HE200 含 T26 基线的累积战役资源 ZIP，不是可直接安装的 APK。它已包含此前新增的车辆、战役菜单及地图，无须先应用旧战役包。

解压，在包目录运行：

```bash
python apply_overlay.py Hatch-0.4-Grille-HE200-T26.apk data.unity3d
```

输出路径须不存在。生成的文件对应游戏包内的 `assets/bin/Data/data.unity3d`；组装时使用 ZIP 里的 `assets/Hatch/` 目录与模组，替换 `AndroidManifest.xml`、`classes4.dex`，并添加 `classes5.dex` 和 `lib/arm64-v8a/libhatchcampaign.so`。不要把这些文件放入手机存档目录。还原工具校验基线、补丁及输出的 SHA-256。两方配置见 `mission.json`，场景回读结果在 `verification.json`。

本版将额外战役的开场、阶段、侦察、命中和击毁文本送入原版顶部消息栏。11 个模组 AI 的名称沿用原版世界空间标识。T26 的车体检修盖固定在甲板，炮塔顶盖保留原有父级。二号 F 主炮支持长按和点射，一个弹匣 10 发、发间隔 0.4 秒、整匣换弹 4.85 秒。

第六版修复了二号 F 的连发注册。德国战役在原发射键上接收按下、松开、滑出和取消，按玩家自己的发射结果扣匣；右上角显示剩余发数及长换弹倒计时。苏德据点从开局可触发；第一波全灭不代表最终胜利，第二波入场后才启用完整全灭规则。战役沿用原版胜负结算及按钮。额外战役绿色准星从当前膛内弹和该弹实际炮口出发，按游戏物理帧检测场景，再投影到手机的游戏画面；它预估中心落点，原有散布依旧生效。


第七版修复了德国开镜按钮的依赖：原版 HUD 重新能在主开火按钮上找到 Button 并切换镜头。点瞄准键会从默认 1 倍进入炮手瞄具，再点返回第三人称；望远镜仍单独切换倍率。附加关卡中，T26、BT7、二号 F 和四号 C 的炮名保留在车辆资料上，主炮由原版初始化，以便实弹和绿色落点读取正常模式的弹速。编组只负责入场，出场后每辆模组车单独排除自己的碰撞体。

从累计第六版重建：先运行 `scripts/prepare_scope_flight.py` 生成两张附加地图及覆盖包，再运行仓库的 `scripts/build_gameplay_refit.py` 生成同签名 APK。用 `tests/check_scope_flight_package.py` 比较旧包、新包和任务包；安卓实机上的触屏、画面和手感需另外验证。
