# 更好的坦克体验 0.1 · 完整 APK

- 合并成员体验，内置一个 `better_tank_experience` 包，旧成员体验包在合并包存在时忽略。
- 补齐玩法包内置及安全升级迁移，恢复所有原有坦克包；修复所有坦克弹道落点、防空预瞄、自行火炮俯瞰入口缺少玩法加载的问题。
- 蟋蟀炮弹池的 `parentTrf` 重绑到炮口，复位后不会回到旧炮位；独立缓存新轮位并把车体碰撞底部与履带底部对齐。
- GLB UV 转为 Unity 方向，已转换过的二号/T30 包保留原 UV；清除未贴图材质从原模板继承的颜色/法线图，复位 UV 缩放/偏移。
- 二号允许按住连发；每个新制作项目有 `continuousFire` 开关，显式关闭能覆盖旧弹匣默认值。
- 语音由准备、敌人发现、实际命中结果、受击、胜利、击杀、切弹触发；正在播报时永久丢弃新事件，不在结束后补播。

## 检验与限制

7 个 C 场景检查、31 个 Python/JVM 用例、50 个已保留的 Unity API 检查通过。实际蟋蟀、二号、T30 的运行时解析/绑定通过；完整 APK 的 9 个包校验、签名、zipalignment 通过。沿用此前交付签名，可覆盖同签名版本。未连接 Android 真机，因此没有完成场景 GPU、履带触地和长时间战斗的实机验证。

本地识别核对上传录音后，有效伤害选“重创目标”，伤害<10 选“命中”，击杀选“目标摧毁”。未找到可确认的“没打中”“没打穿”专用台词，当前未命中采用落点偏低纠偏提示、未击穿采用普通命中提示；这两个事件已实现，但准确台词仍需要补充录音，不能视为已完成语义匹配。
